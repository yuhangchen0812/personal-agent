# 能力范围与边界

## 已实现

命令行与单次任务、Agent Loop、受控文件和 PowerShell 工具、权限与 Plan、Session、流式/取消/重试、用量与预算、Memory/摘要、Skills 和候选评估、自定义子任务、stdio MCP，以及本地 CI 诊断/复验/采纳/回滚。

## 验证范围

当前重点是 Windows CLI 和自编任务的可复现流程。固定响应与实际工具执行分别记录；真实 Qwen 运行曾用于协议和工具链检查，不据此给出通用修复准确率。

Linux 文件型容器已在 GitHub Actions 的 Ubuntu 24.04 环境实际通过构建、非 root/只读/断网运行、卷持久化、新进程恢复和外部 SIGTERM/143 检查；具体提交和运行链接见 [VALIDATION.md](VALIDATION.md)。这一结果不覆盖所有 Linux 主机、Windows Shell 工具或真实模型推理。

原生 Anthropic 远端思考签名兼容仍待实跑。千问 Messages 网关的空签名兼容不等于原生签名验收。

## 已知限制

- 内置 Shell 采用 PowerShell；提供的 Linux 容器主要面向文件型任务。
- 本地路径和权限规则是应用层约束，不是操作系统沙箱。
- 文件/命令副作用不会随聊天消息回滚；工具链中断后应核对实际产物。
- 输入规则的来源声明需要使用者核实；哈希提供版本绑定，不认证内容权威性。
- 候选差异和测试证据仍需审阅；通过当前测试不证明不存在其他问题。
- MCP stdio 程序在本机运行；实现覆盖明确的协议子集，不承诺所有外部服务器即插即用。
- API Key、上下文和源文件片段可能发送到选择的模型服务；真实任务前应核对数据范围。

仓库不包含 Python、已安装依赖、真实密钥、个人会话或本机原始运行日志。依赖清单固定直接版本，未宣称跨机器位级可复现。
