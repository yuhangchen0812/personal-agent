# 能力范围与边界

## 实现范围

项目提供交互式与单次任务 CLI、Agent Loop、文件与 PowerShell 工具、权限与 Plan、Session、流式输出、取消、重试、用量预算、记忆与压缩、Skills、自定义子任务、stdio MCP，以及本地 CI 诊断、复验、采纳和回滚。

它面向本地开发任务和可复现的工程流程。CI 输入与候选需要审阅，工具和服务按当前配置运行。

## 环境与兼容性

| 范围 | 验证方式与边界 |
| --- | --- |
| Windows / Python 3.12 | 本地回归、分组检查、真实文件与进程、新虚拟环境安装 |
| OpenAI-compatible / Anthropic Messages | 固定响应与 SDK 模拟 HTTP 覆盖消息、工具、流式和配置契约；具体服务需按使用配置验证 |
| 原生 Anthropic 思考签名 | 远端兼容仍待实跑；千问网关空签名兼容不等于原生签名验收 |
| Linux 文件型容器 | 提供独立构建、只读/非 root 运行、持久化和停止信号工作流，以对应提交的 CI 为准；不包含 Windows PowerShell 工具 |
| 模型任务质量 | 自编案例用于验证流程，没有通用修复准确率或泛化提升结论 |

固定响应验证执行链路，实际本地工具验证副作用，真实模型请求验证所选服务的具体调用；这些证据范围分别说明。运行方式见[测试与验证](TESTING.md)。

## 执行与数据

- 路径和权限规则是应用层约束，Windows Job 的资源限制不构成文件系统或网络沙箱。
- 对话恢复不重放历史工具，也不恢复旧授权；消息回退不撤销已经发生的文件和进程副作用。
- 候选差异、规则来源和测试范围需要审阅；哈希提供版本绑定，不认证内容权威性。
- MCP 程序在本机运行，当前只覆盖明确的协议子集；外部服务负责其完整参数约束。
- 上下文、源码片段和工具结果可能发送到选择的模型服务，本地记录也可能保存这些内容。

仓库不包含 Python、已安装依赖、真实密钥、个人会话或原始本机运行日志。依赖固定直接版本，未宣称跨机器位级可复现。凭据与报告问题的说明见 [SECURITY.md](../SECURITY.md)。
